This Home Assistant extension dynamically generates sensors for waste collection schedules based on your address, using the offical API for accurate pickup dates.

## 🌟 Features

- 📍 Dynamically creates sensors for various waste types (e.g., Mixed Waste, Paper & Plastic, Food Waste) based on your address.
- 🎛 Easy setup through Home Assistant's UI.
